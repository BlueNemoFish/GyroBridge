# GyroBridge for Lenovo Legion Go — free public beta

Gyro aiming and motion controls on **Windows**, using the Legion Go's own controllers.
No second operating system, no Steam needed, and Legion Space can stay installed.

- **Gyro aiming in PC games**: move the right controller to aim (by default while holding LT).
- **PlayStation mode**: games with built-in gyro aiming get a virtual DualShock 4 with real motion.
- **Emulator motion**: Dolphin, Cemu, Ryujinx and others get real controller motion (DSU / CemuHook).
- **Two players**: right controller = player 1, left controller = player 2, each with its own motion.
- Works with the controllers attached **or detached**, and survives detach/reattach mid-game.

Tested on the original Legion Go (Z1 Extreme), Windows 11. Legion Go S and Go 2: not tested yet — your reports decide what gets supported next.

## Download

Get the latest zip from **[Releases](../../releases)**. Install the
[ViGEmBus driver](https://github.com/nefarius/ViGEmBus/releases) first, then unzip and run `GyroBridge.exe`.
Full instructions are in the `README.txt` inside the zip.

Windows may say "Windows protected your PC" because the beta is not code-signed yet: click **More info → Run anyway**.

## Report how it works for you

Open a **[Beta report](../../issues/new/choose)** — working reports are just as useful as problems.
In the app, stop the bridge and press **Save support report**, then attach that file.
